钱从四面八方来 - 红绿与布林带观察台

推荐运行方式：
1. 在程序目录执行 npm install
2. 开发运行执行 npm run dev
3. 静态构建执行 npm run build，产物位于 dist
4. 单文件构建执行 npm run build:single，产物位于 dist-single/index.html

个人红绿、别名、手工股息、买入价和备注保存在当前浏览器 IndexedDB。
复制程序目录不会迁移浏览器数据；换电脑前请先在页面导出 JSON 备份，再在新电脑导入。

默认数据源为东方财富公开网页接口，仅用于个人开发验证。接口可能调整、限流或延迟。
行情数据仅供参考，不构成投资建议。
